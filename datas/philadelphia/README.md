# Philadelphia Dataset Family

This folder is reserved for prepared variants of Philadelphia public crime incident data.

Philadelphia is planned for later HunchLab-like experiments after the baseline and ETAS pipeline is working.

## Planned Use

- Build cell-day or cell-shift panels.
- Compare history-only, history-plus-time, and richer feature sets.
- Approximate the structure of HunchLab-style models without claiming a full product reproduction.

## Preparation Notes

- Keep Philadelphia variants separate from LAPD and Chicago.
- Use explicit dataset IDs for grid size, target crime type, period, and forecast horizon.
- Store panel-building rules and target definition in metadata.
